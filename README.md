# Container Respawn Tweaker

A MelonLoader mod for The Long Dark that refreshes containers after a configurable number of in-game days.

## Features

- Configurable container respawn interval
- Loot Density options: Low / Medium / High
- Empty Container Chance options: None / Low / Medium
- Protects player-stored items from being deleted
- ModSettings menu support

## Requirements

- MelonLoader
- ModSettings

## Installation

Place `ContainerRespawnTweaker.dll` into:

TheLongDark/Mods/

## Recommended Settings

- Enable Container Respawn: ON
- Respawn Interval: 30 days
- Protect Stored Items: ON
- Loot Density: Medium
- Empty Container Chance: Low
- Debug Logging: OFF
